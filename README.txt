# MHD SHOP — V1

Prototype frontend mobile-first pour la maquette validée.

Fichiers :
- index.html
- style.css
- script.js

La V1 contient :
- accueil
- recherche
- catégories
- cartes produits
- panier de démonstration
- bouton WhatsApp
- navigation mobile
- responsive desktop

Les produits affichés sont des données de démonstration. Avant de vendre un produit numérique réel, vérifie qu'il est autorisé par les conditions du fournisseur/jeu et par les règles applicables.

Pour la suite : backend, comptes clients, base de données, espace admin, commandes et paiement.
